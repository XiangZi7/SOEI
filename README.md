# SOEI · Music Space

基于 `项目任务书_v1.0.md` 和 `ui稿/` 实现的 Vue 3 / Tauri 2 本地音乐空间。当前为 **0.1.0 开发版**；完整 v1.0 的 Windows、多屏、媒体兼容和性能验收尚未完成，详见 [实施记录](docs/IMPLEMENTATION.md)。

## 运行

本次使用 Node 22.22.2、pnpm 10.33.0、Rust stable 1.96.0。原生构建需要 Windows MSVC C++ Build Tools 和 WebView2。依赖版本由 pnpm-lock.yaml 和 Cargo.lock 锁定。

```powershell
pnpm install --frozen-lockfile
pnpm dev                  # 浏览器预览；默认从 1420 开始，占用时依次尝试下一端口
pnpm tauri dev            # 原生窗口；自动选择可用端口并同步窗口地址
```

浏览器可导入本次会话的音频与歌词，设置保存到 localStorage。原生窗口使用 Rust 输出声音，SQLite 保存索引、收藏、设置、队列和播放列表。参考封面仅用于视觉预览，不附带歌曲，也不显示假播放进度。

### 一键播放测试

在画廊底部点击 **播放测试**，自动播放《光的回声 · 播放测试》并进入歌词场景。附带 36 秒自制器乐旋律和 9 句同步测试歌词（无演唱），无需联网或选择文件。浏览器与 Tauri 桌面版都可使用。

- 每 4 秒显示下一句；暂停后进度与歌词停住，继续播放后同步前进。
- 拖动进度到 24 秒应显示「拖动进度，找到这一句」，拖回开头应显示「把声音交给此刻」。
- 浏览器导入时可同时选中音频及同名歌词文件，自动关联；在设置中单独导入的歌词也会按歌曲保留，切歌后恢复（限本次会话）。

测试素材位于 `public/demo/soei-test.wav` 和 `public/demo/soei-test.lrc`，可用 `node scripts/generate-playback-demo.mjs` 重新生成。歌词包含逐词时间标签，可在手书、流光、拼贴、回响、字幕场景观察扫色；这些时间为器乐演示编排，并非人声识别结果。桌面版点击测试时将内置素材保存到应用数据目录的 `playback-test/`，加入音乐库后通过原生音频输出播放。

### 歌词舞台

参考 [Folia](https://github.com/chthollyphile/folia-major) 的歌词构图与 [JIZURA](https://github.com/852wa/JIZURA) 的文字 PV 组合方式，提供「手书、流光、拼贴、回响、字幕、叙事、封面」七种原有场景，并新增 Folia 的「静止、辉光、云阶、错落、环场、心景、印象」七种场景。「字幕」融合大小字、短句竖排、描边、色块和框线；每句由歌曲、行号与分镜种子确定构图，拖回同一句保持原样。「换个分镜」重新组合整首歌的构图，保留歌词和播放进度。从首页打开的视觉预览每 4 秒切句，点击「播放测试」体验真实音频和同步歌词。

布局、响应式、文字和控件均使用 Tailwind CSS。Three.js 按需加载背景光场着色器。歌词引擎参考 Folia 的绝对时间求帧、JIZURA 的布局与入场/停留/退场分层，以独立的毫秒播放时钟计算字素、笔划和镜头，不再由 GSAP 单独计时。同句回拖、暂停与重新进入场景直接恢复对应画面；短句自动收敛动效，普通歌词至少保留 60% 的完整阅读时间。字号按实际容器适配，保留组合字素和英文空格。

普通 LRC 依据行时间同步，逐字效果属于视觉入场。Enhanced LRC（例如 `[00:01]<00:01>你好<00:03>世界<00:05>`）保留词时间并显示逐词进度，词内按完整字素分配；没有词时间时不生成演唱高亮。平衡模式背景最高 30 帧，高质量最高 60 帧；暂停、页面隐藏或光场离屏时停止背景渲染，省电模式和减少动态效果使用静态光场及完整歌词。不支持 WebGL 时自动使用 CSS 背景。当前适配的是播放器的实时歌词表现，不包含 JIZURA 的视频导出或 AE 编辑器。本次从 Folia 移植了解析、语义排版和 Monet 渲染模型，公开富模型统一为毫秒；注音、翻译、罗马音、和声、演唱者与副歌信息接入 Vue 场景。叙事模式提供缓存测量、逐词扫光、滚动浏览及歌词行点击定位。移植来源、AGPL 许可、时间模型和验证范围见 [歌词引擎说明](docs/LYRICS_ENGINE.md)。

## Tailwind 与组件库

主窗口是桌面客户端外壳：44px 标题栏（品牌、当前封面主题名、搜索、设置、窗口控制，空白处可拖窗）+ 可折叠左侧导航（所有歌曲、最近播放、收藏、专辑、歌手、播放列表，底部是导入与歌词舞台入口）+ 独立滚动的内容区 + 右侧可展开的队列面板 + 通栏底部播放条。整窗不滚动，只有内容区滚；窗口在未最大化且未全屏时带 12px 圆角与 1px 内描边，最大化时自动去掉圆角以免露出桌面。封面墙按内容区宽度（容器查询）决定列数，折叠侧栏时列数会跟着变。歌词舞台铺满侧栏与内容区，但标题栏和播放条留在外面，所以进入场景后窗口控制与播放控制仍然可用。

开启任意场景的桌面壁纸后，主窗口自动收为 560×310 的直角半透明双栏播放器，初始贴在当前显示器可用区域右下角，避开任务栏。左侧显示封面、波形、歌曲信息和播放控制，右侧显示同步歌词。按住标题栏空白区域可拖动小窗；松手时距离可用区域任意边缘不超过 24px（逻辑像素）则自动吸附，并保留沿边位置。鼠标移开 650ms 后向该边缘收起，保留 12px 窄边，悬停即可展开；拖回屏幕中央后保持展开。队列、弹窗、键盘导航、窗口拖动或进度拖动期间保持展开。小窗使用透明原生窗口与页面玻璃面板，移除会在裁剪后残留的整窗 Acrylic 背景；原生裁剪同步释放隐藏区域的鼠标点击。收起时窗口位置和尺寸保持不变，避免跨屏缩放跳动；跨屏拖动松手后按目标显示器的缩放和可用区域重新计算吸附。桌面继续使用已选的歌词场景；停用壁纸后恢复主窗口原来的尺寸、位置与外观并返回音乐库首页，保留播放进度。小窗左侧可打开壁纸和场景设置，右侧方框或底部展开按钮停用壁纸并返回音乐空间。手书保留逐字排版和背景动效。独立窗口标题栏为 38px，导航控件至少 44px 高。

### 封面取色主题

界面配色由当前封面生成，不再是固定的一个强调色。取色链路移植自 Folia：封面缩到 50×50 后按加权中位切分取代表色，再由和谐配色方案（类似色、互补、分裂、三角、双色、单色）推出亮/暗一对主题；每个文字色都沿亮度轴推到越过对比度下限（主文字 9:1、次要 4.5:1、点缀 3.2:1）为止，所以保留色相而不会塌成近白或近黑。每首歌以曲目 id 为种子，同一首歌每次进入都是同一套配色；结果按曲目缓存，换回听过的歌不再解码封面。取色失败（例如资源协议缺少 CORS 响应头污染画布）时安静退回兜底主题。

主题通过 documentElement 上的 CSS 变量贯通全局：标题栏、侧栏选中色条、封面墙悬停描边与投影、播放进度与光晕、氛围光束都只读这些变量。悬停封面墙上的任意一张封面，整个界面会按那张封面重新取色。氛围层的封面漂移使用 Web Animations API 播放一条 240 秒首尾无缝的噪声关键帧轨道，交给合成器，没有逐帧 JS；元素预先放大到超过最大位移的两倍，所以平移永远不会把图片边缘拖进画面。省电画质与「减少动态效果」下停止漂移。

首页背景跟随当前歌曲封面，切换时淡入淡出；播放器封面和歌曲信息同步过渡。底部只显示一条进度线，悬停气泡显示对应位置与总时长，悬停不会修改播放进度，拖动与键盘仍可定位。减少动态效果时使用静态切换。

参考界面的英文使用本地 Cormorant Garamond，中日文使用本地 Noto Serif SC；手书场景保留原有楷体字体栈。完整可变字体、英文斜体和 OFL 许可证位于 `public/fonts/`，不依赖在线字体服务。位图参考未提供字体名称，因此字体为按字形匹配的近似还原，详情见 [离线字体说明](public/fonts/README.md)。

- [主题变量](src/styles/tokens.css)：Tailwind v4 `@theme` 定义颜色、字体、字号、间距、圆角、阴影；运行时变量统一动效、层级和背景。
- [常用 class](src/styles/utilities.css)：`flex-center`、`flex-between`、`truncate-text`、`safe-page`、`touch-target` 和语义样式。
- [UI 组件接口](src/components/ui/README.md)：按钮、图标按钮、输入框、选择器、开关、滑块、面板、弹窗和徽标。业务页面已复用；`tailwind-merge` 处理样式覆盖。
- 在终端显示的实际地址后加 `/ui` 操作组件预览（默认 **http://localhost:1420/ui**）。

布局、颜色、字体、间距、响应式和控件状态优先使用 Tailwind。歌词错位排版、中心主封面几何与复合场景光效保留局部 CSS。

## 使用

1. 选择文件或目录导入。原生模式递归扫描、读取标签与内嵌封面，同名 LRC/TTML/VTT/YRC/QRC/KRC/AWLRC 自动关联；扫描可取消。
2. 搜索和分类浏览，收藏歌曲，点击本地歌曲开始播放。控制层提供进度、音量、队列和播放模式。
3. 设置中选择歌词排版、字号、毫秒同步偏移，或为当前歌曲导入 LRC、Enhanced-LRC、VTT、TTML、YRC、QRC、KRC 或 AWLRC。支持 UTF-8、UTF-16、GBK/GB18030，并可读取加密压缩的 KRC。可选择图片与静音视频背景。
4. 场景顶部工具在无操作约 3 秒后隐藏，悬停、焦点或菜单开启时保持可见；底部播放器始终固定显示。`Esc` 返回，输入框外 `Space` 播放/暂停，`Ctrl+K` 搜索。
5. 原生窗口选择显示器后主动启用 WorkerW 壁纸。首次启动不会自动更改桌面。关闭主窗口默认隐藏到系统托盘并继续播放，从托盘菜单「退出 SOEI」真正退出；此前明确保存的关闭行为仍按原设置执行。托盘打开会展开已收起的壁纸播放器。全局组合键、系统兼容情况见实施记录。

导入仅建立索引，不移动或删除原音乐。数据位于 Tauri `app_data_dir`：`soei.sqlite3` 与 `covers/`。备份前退出应用，并保留整个数据目录，包括可能存在的 SQLite WAL 文件。当前没有界面内数据库修复、缓存清理或失效文件重定位工具。

### Folia 辉光场景（2026-10-14）

在歌词场景选择器中选择「09 辉光」，体验按词入场、逐字辉光、唱过后的旋转余韵、整句呼吸和副歌涟漪。底部显示译文；没有译文时预览下一句。暂停、同句回拖和重新进入场景都按绝对播放时间恢复画面，普通 LRC 保留整句且不合成演唱高亮。

选择辉光后，在「设置 → 视觉」调整旋转、呼吸幅度、词距或旧版排版，可重置并自动保存；「换个分镜」改变构图但保留播放进度。省电和减少动态效果时完整静止显示歌词。剩余 Folia 模式仍待移植，进度见 [歌词引擎说明](docs/LYRICS_ENGINE.md)。

### Monet 与六种背景（2026-10-16）

选择「14 印象」体验封面海报、逐词扫光、景深歌词轨道和音频响应。滚轮/触摸/方向键可浏览歌词，点击定位，停止浏览 1.8 秒后回到当前句。「设置 → 视觉 → 舞台背景」可选择流体几何、印象、纸境、潜流、星空或网页；纸境包含像素、条纹玻璃、纸纹、网点与镜头效果，参数自动保存。网页背景在浏览器预览可用，桌面外部网页仍受现有安全策略限制。

当前完成 Folia 7/14 种模式，加上原有七种场景共 14 个选项；其余模式、改编差异与验收范围见 [歌词引擎说明](docs/LYRICS_ENGINE.md)。
